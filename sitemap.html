Apex Logics · apexlogics.org · 24 Free Tools

What can this suite do?

Apex Logics is a free, open-source library of 24 deterministic career and education intelligence tools built for students, career changers, working professionals, counselors, employers, and workforce boards. Each tool is a single self-contained HTML file — no accounts, no servers, no tracking. All computation runs in your browser. Nothing leaves your device.

The suite is organized across three journeys:

📚
Education Path
Credential ROI, scholarships, FAFSA, grad school decisions, 529 savings, test prep
🧭
Career Navigation
Career pivots, automation exposure, skill gaps, severance, job search ROI
💼
Compensation & Benefits
Offer negotiation, equity grants, 1099 vs. W-2, benefits enrollment, total comp
🔒 Zero PII collected Browser-only computation AP2 export on every tool manifest.json for AI/MCP agents CC BY 4.0 open source No install required
