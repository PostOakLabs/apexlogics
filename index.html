What is ApexLogics?

A free, open-source library of deterministic career and education tools. Each tool is a single self-contained HTML file — no accounts, no servers, no tracking. Open source under CC 4.0 BY.

The suite is organized by three journeys:

  • 📚 Education Path — credential ROI, scholarships, FAFSA, grad school decisions
  • 🧭 Career Navigation — pivots, transitions, severance, automation exposure
  • 💼 Compensation & Benefits — offer negotiation, benefits enrollment, total comp

Every tool ships with a manifest.json for AI agent discovery (MCP) and an AP2 export — the agent-protocol mandate format that lets one tool's results flow into the next.
