Error-Correction Triage

Not all errors should be corrected. Not all errors should be corrected the same way. SLA research is clear: over-correction kills fluency; under-correction allows fossilization. This triage tool helps teachers decide which student errors to address now, which to defer, and how to correct — distinguishing global errors (communication breaks down) from local errors (communication succeeds despite the mistake).

📊 SLA correction research: Lightbown & Spada (2006), Truscott (1996), Ferris (1999), Nassaji (2016); corrective feedback taxonomy: Lyster & Ranta (1997)
