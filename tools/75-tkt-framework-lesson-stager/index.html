TKT Framework Lesson Stager

The Cambridge TKT (Teaching Knowledge Test) certifies understanding of lesson frameworks, and for good reason: PPP (Present-Practice-Produce) and Task-Based Language Teaching (TBL) are the two dominant frameworks for structuring English language lessons. This tool generates a complete lesson plan template using either framework — with timing, activity types, materials notes, and assessment touchpoints — named explicitly so you're learning the method as you plan.

📊 PPP and TBL frameworks: Harmer (2007), The Practice of English Language Teaching; Willis (1996), A Framework for Task-Based Learning; Cambridge TKT Handbook (2023)

    CCQ Builder — Concept Check Questions
    Concept Check Questions (CCQs) 3–5 Generated

    CCQs test whether students understand the concept, not whether they remember the rule. Keep them simple, with clear Yes/No or short answers.

    Instruction Check Questions (ICQs) 3 Generated

    ICQs check that students understand what to do before starting an activity — not what to know, but what to do. Ask them immediately before the activity begins.

    CCQ Design Principles
    RULE 1 — Test the concept, not the rule

    Don't ask "What's the rule for past perfect?" Ask "Did this happen first or second?" Target the semantic or pragmatic meaning, not the metalinguistic label.

    RULE 2 — Require a short, clear answer

    Yes/No questions or one-word answers. If the answer requires a full sentence explanation, the CCQ is too complex. Students should be able to respond in under 3 seconds.

    RULE 3 — Don't use the target structure in the CCQ

    If teaching past perfect, don't CCQ with "had finished" in the question — learners may parrot the form without understanding. Use simpler language to test the meaning.

    RULE 4 — Write 3–5 for each language point

    One CCQ is not enough — it may have a correct answer that doesn't actually test understanding. Multiple CCQs triangulate comprehension from different angles.
