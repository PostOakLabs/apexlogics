What is Policy Mandate?

Policy Mandate is a structured JSON export format used across ApexLogics tools. The exported JSON file carries your scenario state — package type, tax estimates, net take-home — in a structured format that lets any AI agent continue the analysis in another tool, create an audit trail, or hand off to a downstream advisor workflow.

The mandate is valid for 90 days and includes a reference to downstream tools such as the Career Break & Reentry Engine (AL-28).
