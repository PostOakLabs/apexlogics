Acknowledgement Audit

After an anomaly, the first question is which commands were confirmed and which were only sent. Enter the commands uplinked in order and the acknowledgements that came back, and this tool pairs them, finds the first command with no acknowledgement, counts the orphaned acknowledgements, and stamps the audit. Re-running the same two sequences reproduces the same finding and the same hash.
