Provenance

A leaderboard number is only as good as the configuration behind it. This tool binds a benchmark configuration to its scored result and produces a configuration key that a reviewer can regenerate. Change one parameter and the key changes, so a quiet reconfiguration cannot hide behind the same headline score.
