Fine-tuning
Lineage

A fine-tuned model is a base model plus a set of datasets, and six months later nobody can list them. Enter the base model, the datasets used with a licence flag for each, and this page derives a lineage key and tells you whether every dataset in the run carries a declared licence. A run with an undeclared dataset is flagged, not averaged away.

Data: SPDX licence identifier convention · no external data
