Chaingraph Sonification

Enter the node identifiers of a chain in order, and this page turns each one into a note using a frozen scale table and a fixed fingerprint. The same chain always yields the same note sequence, so a composition derived from a provenance graph can be regenerated by anyone holding the graph. Change one node id and you hear a different piece.

Data: Equal temperament A4 = 440 Hz (ISO 16) · no external data
