Generative Mesh Descriptor

A commissioned generative sculpture is only re-derivable if the seed and the parameters that produced it are recorded together. Enter a seed and a few integer parameters, and this page derives a mesh descriptor, vertex count, and axis ratios using integer math only. The same seed and parameters always produce the same descriptor, so a client can confirm the delivered piece is the one that was specified.
