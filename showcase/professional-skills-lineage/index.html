Professional Skills
Lineage

A degree is a claim about a person. A skills lineage is a claim you can check. Enter a qualification code, the issuing body, the skills that qualification is asserted to carry, and the assessment level each was verified at, and this tool derives a stamped lineage in which every skill carries the qualification it came from and its own derivation key. The employer holding the credential re-enters the same values and gets the same keys back. Nothing leaves the browser, and no registry has to be trusted for the derivation to be checkable.

This card is the natural parent for the Workforce Credential Batch and Credential Revocation Audit tools elsewhere in this suite: both accept its stamped output through a handoff link, which raises their chain depth to 1.

Data vintage: 2026 · ApexLogics native, no cross-server pointer
