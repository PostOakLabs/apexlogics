OCG-Industries Showcase · Cluster 15 EMIR

EMIR Trade Report
Validation

Enter a trade report's identifiers, action type, execution date, and notional, and this tool runs the field completeness and format checks a Trade Repository applies before acceptance: LEI, UTI, and UPI format, currency and date format, and whether the notional is positive where the action type requires it. It returns a named first failure and a submittable or would-reject verdict. Format checks only. This demo does not apply the full Trade Repository rule set, and it never checks an LEI against a register.

Data: Regulation (EU) 648/2012 (EMIR) as amended by EMIR Refit · ISO 17442 LEI · ISO 4217
