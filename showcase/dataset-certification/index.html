Certification

Analysis time spent on uncertified data is analysis time spent twice. Enter the run range, the subsystem quality flags, and the certification digest recorded for the dataset, and this tool counts the runs, finds any subsystem flagged bad, recomputes the digest, and stamps the certification. Re-running the same range and flags reproduces the same digest and the same hash.
