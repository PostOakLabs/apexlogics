Pipeline Run
Fingerprint

A result attributed to a pipeline is only checkable if the pipeline is pinned. Enter the pipeline name, its version tag, the reference build, and the parameters the run used, then paste the fingerprint recorded with the result. This tool recomputes the fingerprint and tells you whether the run you are looking at is the run that was recorded. Re-running the same pins reproduces the same fingerprint and the same hash.
