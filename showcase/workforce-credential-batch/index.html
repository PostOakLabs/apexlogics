Credential Batch

Verifying credentials one at a time is where the cost lives, and duplicates are where the fraud lives. Paste a batch of credential identifiers with the issuer they claim, and this tool normalizes them, finds duplicates and malformed entries, derives a per-credential key and a single batch digest, and stamps the lot. Re-running the same batch reproduces the same digest and the same hash, so two parties can compare one number instead of two lists.
