Verification

A split-secret hunt only works if the final combination cannot be faked and cannot be opened early. This tool takes the fragments a solver has collected, checks that the full set is present, and combines them into a single reveal key in a fixed order. The same fragments always produce the same key, so a "who solved it first" claim can be checked by anyone holding the fragments.

Scope. This page ships the verification half only. It does not claim a deployed physical geocache, and no physical placement, hardware, or field deployment exists behind it. What runs here is the client-side fragment check.
