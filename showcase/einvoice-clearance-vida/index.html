E-Invoice Clearance
(ViDA)

Enter an invoice's structural fields and this tool runs it against five named clearance rules: an invoice number present, a valid issue date, both VAT ids present and long enough, the VAT arithmetic reconciling to the rate, and the total reconciling to net plus VAT. Every rule either holds or it does not, so the same invoice always returns the same verdict and the same named rule when it fails, instead of a reviewer's judgment call that changes depending on who is looking.

Data: EN 16931 e-invoicing semantic model · Council Directive (EU) 2025/516 (ViDA)
