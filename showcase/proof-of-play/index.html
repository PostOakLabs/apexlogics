Proof of Play

A contested run is usually one person's word against a leaderboard. This tool folds a run's checkpoints into a single digest where each checkpoint absorbs the one before it, so removing a checkpoint or swapping two of them changes the result. Enter the same checkpoints in the same order and you get the same digest every time, which is what makes a run claim checkable by someone who was not there.
