Readiness Score

Cluster study queues drop projects that cannot show site control and commercial readiness, and withdrawal penalties follow. Enter a project's readiness checklist below and this page returns an integer score from a frozen weight vector, a tier, and the exact list of failed criteria. The same checklist always produces the same score and the same hash, so a developer and a reviewer can compare the same number.
