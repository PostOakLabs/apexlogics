Exhibit Visit Receipt

An exhibit claims a visitor route, and there is no way to check it after the fact. Enter the stations a visit touched, in order, with the integer dwell in seconds at each, and this page folds them into a visit receipt and checks the route against the exhibit's declared station order. The same route always folds to the same receipt, so a reported visit can be re-derived.

Scope. Every value here is entered by hand. This shows what an exhibit receipt would look like and that it is reproducible. It does not capture anything from a physical space, and it holds no visitor data.

Data: no external data

Inputs STEP 1
For example entry,atrium,vault,exit
One per line as station:dwellseconds, for example atrium:120. Order is the order you list them.
