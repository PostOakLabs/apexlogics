Agent Memory
Lineage

When an agent does something surprising, the useful question is which policy and which remembered state produced it. This tool derives a memory descriptor that stamps both, and flags a decision whose policy ancestor is missing. Same policy, same memory state, same decision label gives the same descriptor, so a decision log can be re-derived rather than trusted.

Data: no external data
