Letter of Credit
Document Set

Mark which of the eight standard document types the credit requires, mark which of those were actually presented, and enter the presentation day, the credit's expiry day, and the presentation period. This tool derives which required documents are missing, whether the presentation landed within expiry, and a discrepancy count from those two checks together, so the finding is something the other side can rerun against the same facts rather than a judgment call to argue about.

Data: ICC UCP 600 Art.14, Art.6 · ICC ISBP 745
