Verification Reuse Check

Re-collecting documents you already hold is the expensive half of onboarding. Enter which checks the original verification covered, the day it was performed, and the day you want to rely on it, and this tool compares the coverage against a frozen requirement set, computes the age in whole days, and decides whether reuse is inside the window you stated. Re-running the same record reproduces the same decision and the same hash.

Data: frozen showcase requirement set · user-entered reuse window
