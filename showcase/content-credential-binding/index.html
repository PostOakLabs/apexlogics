Content Credential Binding

A content credential is only useful if a later edit shows up. Enter a small set of credential fields twice, once as originally issued and once as you received it, and this page computes a binding fingerprint for each and tells you whether they match. If any field was changed between the two versions, the fingerprints diverge and the page names the fields that moved.
