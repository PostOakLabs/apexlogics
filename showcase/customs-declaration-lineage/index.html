Customs Declaration
Lineage

Enter a declaration's core fields, mark which supporting documents you have on hand, and set an amendment index. This tool checks completeness, checks the commodity code and origin country against their expected formats, and derives a digest from the whole declaration plus the amendment number, so amendment 1 and amendment 2 of the same shipment leave two different, comparable fingerprints instead of one record that got quietly overwritten.

Data: Regulation (EU) 952/2013 (Union Customs Code) Art.162, Art.173 · WCO Harmonized System
