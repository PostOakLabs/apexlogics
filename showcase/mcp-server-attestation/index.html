MCP Server
Attestation

Paste a server's advertised tool surface twice, once as the baseline and once as a later check, one line per tool in the shape name colon description. This tool fingerprints each paste, compares them line by line, and flags whether the surface matches what you were originally told to expect. A tool description that changes after you have already reviewed and trusted it is a live path for an agent to be redirected, and a structural comparison catches that drift even when the change is small.

Data: Model Context Protocol specification · illustrative demo, no external data
