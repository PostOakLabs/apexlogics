Getting started

Connect in under a minute

The server speaks standard MCP over Streamable HTTP with no authentication, so any MCP host can connect with just the URL.

  1. Claude — Settings → Connectors → Add custom connector → paste https://mcp.apexlogics.org/mcp. No OAuth prompt; it connects immediately.
  2. ChatGPT (developer mode) — Settings → Connectors → Create → server URL https://mcp.apexlogics.org/mcp, no authentication.
  3. Any other MCP client — point a streamable-http transport at the endpoint.

Then just ask — "what tools help with student loan strategy?", "build a workflow for evaluating a job offer", or "find career pivot tools". The server returns direct links to the relevant calculators so you can open them in one click and run the numbers yourself.

What's exposed

The 6 tools

All six tools carry readOnlyHint: true — nothing mutates state, nothing writes anywhere. find_tool ranks the catalog for one specific calculator; find_chain ranks multi-tool decision journeys; run_chain executes a matched chain server-side with a verifiable composite hash; verify_execution_hash independently recomputes any artifact's hash; list_apexlogics_tools returns the full unranked catalog; build_workflow_links returns deep-link URLs for named workflow pages.

Tool nameWhat it does
Discovery
find_tool Ranked BM25 search over the 168-tool catalog for ONE specific calculator answering a single question — e.g. "ISO AMT exposure", "teacher pension estimate". Returns best-matching tools with URLs and Policy Mandate types, most relevant first.
find_chain Ranked BM25 search over the OpenChainGraph chains — multi-tool decision journeys — for a MULTI-STEP goal spanning several tools, e.g. "plan a career pivot", "equity exit and 83(b)". Returns matching chains with their ordered steps, most relevant first.
Execution & verification
run_chain Execute a named ChainGraph chain server-side (OpenChainGraph §21). Runs each kernel-backed step deterministically, threads each step's execution_hash into the next step's parent_hashes, and folds the outputs into one composite artifact with a reproducible composite_execution_hash. Zero network, zero PII.
verify_execution_hash Independently recompute and verify a Policy Mandate artifact's SHA-256 execution_hash (OpenChainGraph §4) — confirms an artifact wasn't tampered with after export.
Catalog & workflows
list_apexlogics_tools Search the full ApexLogics catalog (168 client-side tools). Accepts an optional query keyword, category slug filter, and limit (max 50). Returns tool titles, descriptions, direct URLs, and Policy Mandate types. Categories: education_path_roi, compensation_offers, career_transition_mobility, licensing_credentials, student_finance_debt, workforce_development, immigration_visa, selected_studies, hr_analytics, obbba_student_loans, equity_tax, freelance_tax.
build_workflow_links Return ordered, deep-link URLs for a named multi-tool workflow chain (40 chains — e.g. new-offer-suite, mba-aspirant-playbook, equity-compensation-decisions, student-loan-payoff-decisions) with handoff notes describing which outputs feed the next step. Call with no argument to list all available chains.

🔗
Policy Mandate handoff

Tools that export Policy Mandates can pass their output directly to the next tool in a chain via the ?ap2= URL parameter. The mandate travels in the URL — it is never transmitted to a server — and the destination tool pre-fills from it automatically. All 168 tools are zero-network after page load.

Behavior & privacy

How the server treats your data

🔒
Zero PII, by design
The MCP server collects no accounts, no keys, and no personal data. Tool inputs are processed transiently to compute a response and are not stored, logged, or retained. Nothing is shared with or sold to third parties. The same rule that governs the website applies here: use synthetic or anonymised inputs only.
🧮
Tools run client-side
The MCP server returns deep-links to tools — it does not run the calculations itself. All 168 tools execute entirely in your browser as self-contained HTML files. No server receives your inputs. Deterministic: same inputs, same outputs, every time.
👁️
Read-only, annotated
Both tools declare readOnlyHint: true. Nothing on the server or in your environment is modified by any call — the server looks up, links, and returns.
⚡
Fast and globally served
Runs on Cloudflare Workers edge infrastructure — no cold starts, globally distributed. Health check: mcp.apexlogics.org/healthz. Source is open on GitHub.
